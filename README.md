## Pages

THe following is a description of all of the pages and the sitemap.

All pages will have a header, a footer and a unified color scheme.

### Header

The header will have the logo that can be clicked to go to the homepage, a cart button, and a link to the "about" and "shop" pages.

### Footer

The footer contains the following:
- Copyright
- Contact Us box
- Terms
- Privacy Policy
